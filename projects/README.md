# Projects

A personal portfolio archive of my work across artificial intelligence, game programming, and computer-science fundamentals (GitHub: [Saneaven](https://github.com/saneaven)). The collection spans solo builds, coursework, and team projects, with a recurring emphasis on building things from first principles: writing the core systems by hand to understand why they work, and reporting honest findings.

## Categories

### [Artificial Intelligence](ai/README.md)

Machine-learning and AI work spanning the full range of the field: from exploratory data analysis and classical regression, through deep learning built from scratch, to reinforcement learning, transformers, and the modern generative-AI stack.

- **[Novel Buds](https://github.com/saneaven/NovelGenerator)**: an AI-agent workspace to plan, write and illustrate a novel in one place *(standalone repo)*.
- **[Next Gen Dynamics](https://github.com/saneaven/NextGenDynamics)**: reinforcement learning that teaches a six-legged robot to walk, navigate and chase in simulation *(standalone repo)*.
- **BuzzaMaker**: a reinforcement-learning portfolio generator pairing a dual-stream Transformer with a PPO agent.
- **Deep Learning**: backprop by hand in NumPy, CNNs through ResNet50V2 transfer learning, and a Double DQN agent.
- **Generative AI**: an eight-module, build-by-hand tour from decoding strategies to a synthesise -> QLoRA-fine-tune -> deploy pipeline.
- **Jamo Tokenization Translator**: a Korean BPE tokenizer that decomposes syllables into jamo, evaluated on a Korean-to-English Seq2Seq Transformer.
- **LLM Card Game**: a turn-based card battler with one Gemini agent as the rules engine and a second as the opponent.
- **Movie Revenue Prediction**: a regression study predicting box-office revenue from movie metadata.
- **NYC Taxi Analysis**: an exploratory analysis joining and cleaning ~14.8M NYC yellow-taxi trip and fare records.

### [Game Programming](game/README.md)

Engine and gameplay programming built from the ground up: hand-written physics and collision, data-oriented architecture, finite-state-machine and behavior-tree AI, and the data tables and level systems that drive a game.

- **Q by Noflex**: a side-view roguelike platformer on a custom C++ engine with an ECS core and parallel system scheduler.
- **An Omen In The Mirror**: UI/UX design and in-engine implementation for a first-person narrative puzzle game.
- **Game AI Projects**: three studies in classic game-AI algorithms: behavior trees, A\* pathfinding, and terrain analysis.
- **The Forest of Food**: a top-view seasonal cooking adventure on an in-house engine.
- **Bounce NDS**: a 2D physics ball-platformer with no jump button, built in the browser.
- **Painter**: a 2D color-swapping puzzle platformer where one rule reaches from collision up to level design.
- **Sonar Soul**: a side-view action game where sonar waves disable enemies by matching musical notes.
- **DragonSword Legend**: a Korean-language Windows-console RPG in pure C with the full RPG loop.

### [Computer Science](computer%20science/README.md)

Coursework and self-contained projects on the fundamentals (algorithm design, relational databases, and image processing) implemented from scratch, with attention to correctness, complexity, and measured performance.

- **Algorithms**: classic implementations across brute force, divide and conquer, dynamic programming, greedy, and branch-and-bound.
- **Database (MySQL)**: SQL on a rare-books schema, ER design, and a Java/JDBC servlet app running social-graph analytics.
- **Image Operations**: a from-scratch image-processing toolkit with point operations, convolution, histogram equalization, and a DFT/FFT suite.

## Skills demonstrated

Across these categories the work covers a broad stack: Python with PyTorch and TensorFlow / Keras, scikit-learn and the HuggingFace ecosystem, LLM APIs, C and modern C++ with custom and in-house game engines, JavaScript in the browser, Unreal/UMG, MySQL with Java/JDBC, and image processing. All of it is unified by a consistent habit of building core systems by hand, reasoning about correctness and performance, and reporting results honestly.
