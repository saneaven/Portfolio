
문제:
각 방향으로 최대 10^9 크기의 격자와 직사각형 집합(최대 10^5개)이 주어졌을 때, 각 셀을 덮는 직사각형 수의 분포를 계산하세요.

인덱스 C에 있는 값이 정확히 C개의 직사각형으로 덮인 전체 영역(또는 셀 수)과 같은 맵을 반환하세요(모듈로 7001, 오버플로 방지).

직사각형은 왼쪽 위와 오른쪽 아래 모서리로 정의됩니다.
(좌표계는 왼쪽 위가 중심이고 X축 양수는 오른쪽, Y축 양수는 아래쪽이라고 가정합니다.)

  |01234567   X
--+----------->
0 |
1 |          직사각형은 3 2 6 5로 제공됩니다.
2 |   C--+   여기서 (3,2)는 왼쪽 위 모서리이고 (6,5)는 오른쪽 아래 모서리입니다.
3 |   |  |
4 |   |  |   직사각형의 면적은 4*4 = 16입니다.
5 |   +--C
6 |          일반적으로 면적( x1,y1,x2,y2 ) = (x2-x1+1)*(y2-y1+1)
Y V

참고:
1x1 직사각형은 ( x,y,x,y )로 정의됩니다.

직사각형 2: 5 1 9 7

알고리즘:

아이디어는 격자의 모든 셀 또는 행을 처리하지 않는 것입니다(각각 10^18 및 10^9).
이벤트 기반 프로그래밍 접근 방식(스캔 알고리즘)을 사용합니다.

  |0123456789   X
--+----------+-->
0 | +------+ | <--- 0111111110  직사각형 시작
1 | |      | |
2 | | +----++| <--- 0122222221  직사각형 시작
3 | | |    |||
4 | +-+----+||
5 |   |     || <--- 0001111111  직사각형 끝
6 |   |     ||
7 |   +-----+|
8 +----------+ <--- 0000000000  마지막 직사각형 끝 (완료)
Y V

위 다이어그램(위에서 아래로)을 사용합니다.
1)  0행: 직사각형 시작.
    8개 셀은 개수 1
    2개 셀은 개수 0
2) 다른 직사각형이 시작되므로 개수가 변경됩니다.
    먼저 빈도를 업데이트합니다.
    8개 셀은 개수 1    x2  (이러한 개수를 가진 행이 2개 있었으므로)
    2개 셀은 개수 0    x2
    따라서 빈도: 0->4   (덮는 직사각형 수 -> 셀 수)
                    1->16

    새 직사각형을 고려하여 개수를 업데이트합니다.
    7개 셀은 개수 2
    2개 셀은 개수 1
    1개 셀은 개수 0
3) 직사각형 끝 (5행)
    먼저 빈도를 업데이트합니다.
    7개 셀은 개수 2    x2
    2개 셀은 개수 1    x2
    1개 셀은 개수 0    x2
    따라서 빈도: 0->4+1*2    = 6
                    1->16+2*2   = 20
                    2->7*2      = 14
    새 직사각형을 고려하여 개수를 업데이트합니다.
    7개 셀은 개수 1
    3개 셀은 개수 0
4) 마지막 직사각형 끝 (8행)
    먼저 빈도를 업데이트합니다(다시 사용하지는 않지만 건너뛸 수 있음).
    7개 셀은 개수 1    x3  (이러한 개수를 가진 행이 3개 있었으므로)
    3개 셀은 개수 0    x3
    따라서 빈도: 0->6    +3*3 = 15
                    1->20   +7*3 = 41
                    2->14        = 14

**번역:**

**문제:**

각 방향으로 최대 10^9 크기의 격자와 최대 10^5개의 직사각형 집합이 주어졌을 때, 각 셀을 덮고 있는 직사각형 개수의 분포를 계산하세요.

인덱스 C에 있는 값이 정확히 C개의 직사각형으로 덮인 전체 영역(또는 셀 개수)과 같은 맵을 반환하세요. 결과는 7001로 나눈 나머지 값입니다(오버플로 방지).

직사각형은 왼쪽 위와 오른쪽 아래 모서리 좌표로 정의됩니다. 좌표계는 왼쪽 위가 (0,0)이고 X축 양수 방향은 오른쪽, Y축 양수 방향은 아래쪽이라고 가정합니다.

예를 들어, 3 2 6 5는 왼쪽 위 모서리가 (3,2)이고 오른쪽 아래 모서리가 (6,5)인 직사각형을 나타냅니다. 이 직사각형의 면적은 4*4 = 16입니다. 일반적으로 면적(x1, y1, x2, y2) = (x2-x1+1)*(y2-y1+1)입니다.

참고: 1x1 직사각형은 (x, y, x, y)로 정의됩니다.

예시:

*   직사각형 1: 1 0 8 4
*   직사각형 2: 5 1 9 7
*   직사각형 3: 3 2 6 5

위의 직사각형들을 격자에 표시하면 다음과 같습니다.

```
  |0123456789   X
--+----------+-->
0 | +------+ |
1 | |   +--++|
2 | | +-++ |||
3 | | | || |||
4 | +-+-++-+||
5 |   +-++  ||
6 |     |   ||
7 |     +---+|
8 +----------+
Y V
```

각 셀에 표시된 숫자는 해당 셀을 덮고 있는 직사각형의 개수입니다.
