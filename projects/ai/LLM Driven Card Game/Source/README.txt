If you want to see the code, I recommend opening this folder through VS Code.

---- How to play ----

1.  Run the PlayGame.bat file.
2.  When it's your turn, type anything you want to do.


---- Important!! ----

- The .env file contains my API key. Therefore, please do not share this file with anyone.
- Because the API key is the free version, if the usage limit is exceeded, you can no longer use it. The usage limit resets daily, and it can be used up to 25 times per day. Please be aware that two uses are counted during the enemy's turn.
- The API key is valid until May 1st. After that, it cannot be used. If you try to use it after that date or if the quota is exceeded, please obtain a new API key from https://aistudio.google.com/ and put it in the .env file.
- If an error occurs before then, please let me know, and I will resolve it.
