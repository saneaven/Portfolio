*Prototype Name: Painter

*Prototype High Concept:
	“prototype1” is a 2D platformer game, about a boy, who cannot suddenly see the color,
	 going on an adventure to get back the color he lost.  The player can break through the
	 monsters and obstacles by changing the color of them.

*Build Instructions:
	You can build our project in latest version of Visual Studio 2019. Please build in Release Mode.

*How To Play:	
	The player can change their own color by pick up the color items on the map.
	Player can throw the color ball, and paint the enemies and blocks.
	Player can go through the block, if the color of player and block is same. (This also applies between enemy and blocks.)
	If the enemy and player has the same color, player can defeat the enemy by step on the enemy.
	To clear the stage, player should reaches the end of the map.

*Game Controls:
	← (Left arrow key): Move left
	→ (Right arrow key): Move right
	↑ (Up arrow key): Jump
	Spacebar: Throw the color ball
	Z key: Change the color of the ball
	R key: Restart the game
