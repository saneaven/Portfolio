## Highlights

- **[Novel Buds](https://github.com/saneaven/NovelGenerator)**: an AI-agent workspace to plan, write and illustrate a novel in one place.
- **[Next Gen Dynamics](https://github.com/saneaven/NextGenDynamics)**: reinforcement learning that teaches a six-legged robot to walk, navigate and chase in simulation.
- **[BuzzaMaker](projects/ai/BuzzaMaker/README.md)**: a reinforcement-learning portfolio generator pairing a dual-stream Transformer with a PPO agent.
- **[Jamo Tokenization Translator](projects/ai/JamoBased%20Tokenization%20Translator/README.md)**: a Korean BPE tokenizer that decomposes syllables into jamo, evaluated on a Korean-to-English Seq2Seq Transformer.
- **[Q by Noflex](projects/game/Q%20by%20Noflex/README.md)**: a side-view roguelike platformer on a custom C++ engine with an ECS core and parallel system scheduler.
